# Трекер

Личный трекер задач: PWA на одного человека. Лежит рядом с портфолио и
публикуется вместе с ним в `dist/tracker/`: адрес — адрес сайта плюс `tracker/`.

## Данные

- Всё хранится в IndexedDB на устройстве. Политика безопасности страницы
  (CSP) не пускает запросы на чужие адреса: данным просто некуда уйти.
- В репозиторий личные данные не попадают никогда: задачи, файл импорта,
  копии, бюджет. Шаблоны файлов — в `.gitignore`. Если JSON всё-таки
  оказался в `tracker/`, сборка падает (`tooling/build-tracker.mjs`).
- Резервная копия: Settings → Export backup, файл `tracker-backup-ГГГГ-ММ-ДД.json`.
  Восстановление из неё заменяет всё. Копия — это и перенос на новый телефон.
  В копии и настройки, и вложения (base64); копии прошлой версии читаются.
- Вложения задач (фото, PDF, документы до 25 МБ) лежат в той же базе
  (хранилище `files`, версия базы 2) и тоже никуда не уходят.

## Первый запуск

Чистый трекер открывается не пустым: пять нейтральных сфер (Work, Personal,
Health, Home, Learning), пять задач-подсказок — две на сегодня, три в All —
и цель-пример (Read 12 books). Подсказки говорят, где что: тап по задаче,
смахивание, вечерний Plan, перетаскивание, Settings → Appearance. Это
обычные задачи и цель — удаляются как любые. Задачи и цель появляются,
только если в базе ещё ничего нет; трекер с данными первый запуск не
проходит заново (метка `seeded`). Тексты — `DEFAULT_SPHERES`, `STARTER_TASKS`,
`STARTER_GOAL` в `src/logic.js`.

## All

**All** — задачи без сферы (раньше Inbox): чип в поле новой задачи, пункт
меню сфер, группа в Plan и плитка в Spheres. Это не «все задачи», а общая
корзина для того, что ни к какой сфере не относится. В импорте сфера
`All`, `Inbox` или «Входящие» значит «без сферы».

## Настройки

Settings (шестерёнка на Today; закрывает крестик на том же месте; шапка
с названием и крестиком не уезжает при прокрутке):
оформление (ниже), сколько задач помещается в день (3, 5 или без лимита), куда попадают новые
задачи с экрана Today (на сегодня или без даты), какой экран открывать при
запуске, анимации (Full или Fewer — без скольжения и пружин; при «Уменьшить
движение» в настройках iPhone их и так меньше).

## Оформление

Settings → Appearance: **Style** — Minimal или Colour, **Theme** — Auto,
Light или Dark; итого четыре вида. **Auto** (по умолчанию на новом
устройстве) — как iPhone: тёмная, когда тёмный он, и переключается вместе
с ним прямо в открытом приложении. Смена — наплывом (View Transitions),
после него крестик в шапке на миг становится галочкой: сохранено. Крестик
с поворотом сжимается и гаснет, галочка прорисовывается линией, кнопка чуть
подпрыгивает, потом крестик возвращается — 1,25 с; с Fewer — просто галочка.

- **Minimal** — как было: сферы различаются только глифом, цвет в приложении
  один — красный, «срочно».
- **Colour** — у каждой сферы свой цвет: заливка плитки сферы и метки сферы
  на задаче; глиф сферы в меню, в заголовках Plan и в Overview — в кружке её
  цвета. Палитра из 8 цветов по референсу: Olive, Lavender, Apricot, Mint,
  Slate, Lilac, Plum, Khaki. Красного и оранжевого среди них нет — красный
  значит «срочно». Новая сфера берёт первый свободный цвет; сменить — в её
  шторке «⋯» (там же образцы, только в Colour). Сферы из времени до цветов
  получают цвет по порядку при первом запуске.
- В данных у сферы — название цвета (`color: "olive"`), не hex: сами цвета —
  токены темы (`--sph-*` в `app.css`), новая тема может задать свои.
- **Dark** — те же роли цветов на тёплом почти чёрном (`:root[data-theme='dark']`
  в `app.css`): светлый текст, красный чуть светлее, плашка вкладок, меню и
  тосты — тёмно-серые, зерно — светлыми крупинками (`grain-dark.png`). `color-scheme: dark` —
  системные поля и выбор даты тоже тёмные.
- Настройки живут в IndexedDB и приходят позже первого кадра. Чтобы тёмная
  тема не мигала светлой при запуске, копия оформления лежит в localStorage,
  и `src/look.js` (обычный скрипт в `<head>`) ставит её до отрисовки.
- Строки, где значок стоит рядом с подписью (метки сфер, меню, заголовки),
  — целой высоты: при дробной (1.3 × 17) браузер округляет подпись по-разному
  в разных местах экрана, и она съезжает на пиксель от значка. У Geist
  середина заглавных совпадает с серединой строки, так что при целой высоте
  значок стоит ровно по заглавным.
- В Colour глиф в цветном кружке — 12 px: разница с кружком (22, 20, 18)
  чётная, и центр глифа — ровно в центре кружка, без полупикселя в сторону.
- Треугольник поднят на 1 из 14: «вес» у него внизу, и точно по центру
  рамки он кажется опущенным.

## Экран и жесты

- Текст не выделяется и долгое нажатие не зовёт «Скопировать»: долгое
  нажатие здесь перетаскивает задачи. В полях ввода выделение, вставка и
  каретка — как обычно.
- «Встряхните, чтобы отменить» — функция iOS, со страницы её не выключить.
  Выключается в iPhone: Настройки → Универсальный доступ → Касание →
  Встряхивание для отмены.
- Экран не увеличивается ни двойным тапом, ни щипком: `user-scalable=no`,
  `touch-action: pan-x pan-y`, жесты Safari (`gesture*`) и движение двумя
  пальцами гасятся.
- Настройки въезжают справа, шестерёнка перетекает в крестик; закрытие —
  обратно, экран под ними не перерисовывает появление. Между вкладками —
  наплыв. Это View Transitions (iOS 18+); на старом iOS — без перехода.
- Отклик на тап: кнопки проседают и пружинят обратно, пилюли дня на Today
  отзываются (пилюля задачи подсвечивает её строку, пустое место открывает
  поле).
- Вибрация на нажатие. iOS щёлкает только переключателем `<input switch>`,
  который переключил палец, — в том числе через его `<label>`; щелчок из
  кода (`click()`) на iOS 27 не вибрирует, `navigator.vibrate` в Safari нет
  (проверено страницей `haptic.html`). Поэтому в кнопке с отзывом лежит
  прозрачный label на всю её площадь со скрытым переключателем
  (`withTick` в `src/ui.js`): палец нажимает label, iOS щёлкает, кнопка
  срабатывает следом — в следующей задаче, иначе её перерисовка убрала бы
  label раньше щелчка. Щёлкают: галочка задачи, подзадачи и шага цели,
  −/+ у цели, Delete (смахиванием и двумя тапами), пункты меню,
  приоритет, пилюли дня на Today (эти — сразу: ставят фокус в поле).
- Крутилка щёлкает на каждом делении. Переключатель щёлкает, когда палец
  перегоняет его ползунок на другую сторону, поэтому на линейке лежит
  прозрачный переключатель: до касания — на всю линейку, от касания —
  родного размера, и на каждом делении прыгает вбок, так что палец
  оказывается то на левой, то на правой его половине (`src/views/dial.js`;
  найдено лабораторией, режим E). Правила WebKit (`CheckboxInputType.cpp`):
  за пальцем переключатель следит только через 200 мс после касания, и
  первый перещёлк зависит от того, где в нём оказалась точка касания в этот
  момент. Поэтому первые 280 мс он стоит на месте, точка касания — на
  стороне ползунка, и только потом едет за пальцем: первые ~0,3 с движения
  без щелчков. Касание пальца на переключателе крутилка не отменяет
  (`preventDefault` глушил и его), фокус поля на тапе держит `mousedown`;
  после сдвига вёрстка пересчитывается сразу. Перетаскивание и смахивание
  не щёлкают.
- После «добавить» клавиатура уходит, новая задача подсвечивается, а поле
  возвращается к умолчаниям: сфера экрана, день по настройке, без времени и
  приоритета.
- Системный календарь и выбор времени на iPhone не закрываются от касаний
  дня или месяца: выбор сохраняется, когда календарь закрыли (поле отпустило
  фокус; `pickerInput` в `src/ui.js`). В других браузерах выбор закрывается
  сам — там сразу.
- Сообщения — плашкой над вкладками; об удавшемся (удалено, заменено,
  добавлено) — с галочкой в кружке, с пружинкой снизу. Пока открыта шторка —
  сверху; уходящая шторка уже не в счёт, так что сообщение не прыгает.
- Меню сфер раскрывается из кнопки — растёт от её угла, пункты лесенкой
  следом; закрывается коротким затуханием. Пока на iPhone набирают текст,
  меню открывается над полем: под полем клавиатура и плавающая над ней
  панель «^ v ✓» (iOS 26+), которая закрывала нижние пункты.
- Второй тап удаления: кнопка «взводится» — заливка бежит слева направо,
  подпись (Tap again to delete, Sure?) поднимается на место прежней, с
  щелчком.
- Шторка меняет высоту плавно (0,44 с), когда содержимое растёт или
  сжимается — например, при заметке «Tomorrow is full» в шторке даты; сама
  заметка проявляется снизу вверх.
- Зерно бумаги — часть страницы: едет вместе с содержимым при прокрутке; у
  плашки вкладок и у шторки своё (рамка шторки стоит, прокручивается
  `.sheet-body`). Плитка 384 px на 128 pt: на экране iPhone крупинка — один
  пиксель; для тёмной темы — своя, светлыми крупинками
  (`node tooling/tracker-icons.mjs`). Наложение обычное: с soft-light снимок
  для перехода между экранами готовился в 3–7 раз дольше. Настройки не
  «поднимаются» при появлении, как другие экраны: на время подъёма экран
  становится отдельным слоем, и зерно в закреплённой шапке двоилось.

## Лаборатория вибрации (эксперимент)

Вопрос: даст ли iPhone системный щелчок на каждом шаге степпера за одно
непрерывное движение пальца, если палец лежит на настоящем
`<input type="checkbox" switch>`. Проверено до неё (тестовая страница
`haptic.html`, iOS 27): щелчок из кода (`click()`) не вибрирует,
`navigator.vibrate` нет, вибрирует только переключатель под пальцем.

Экран `#/lab`, вход — Settings → Experiments → Open haptics lab. Код —
`src/views/lab.js`, стили — конец `app.css`. Флаг `IOS_HAPTIC_EXPERIMENT`
в начале `lab.js`: `false` — нет ни экрана, ни входа. Степперы приложения
от лаборатории не зависят.

Дорожка 0–100, старт 50, шаг — 12 точек пути пальца; направление —
вертикально или горизонтально, переключатель — прозрачный или видимый.
Режимы: A — до касания растянут на всю дорожку, с первым движением
сжимается до родного размера и едет за пальцем; B — растянут на всю
дорожку; C — стоит в центре, начинать внутри пунктира (промах лог
помечает MISSED); D — без него (контроль); E — как A, но на каждом шаге
прыгает вбок, чтобы палец оказался на другой его половине.
Итог на iPhone (iOS 27): режим E работает — по нему сделана крутилка.
Вибрацию лаборатория не вызывает ничем — только пишет, что делают сам
переключатель и палец. Лог — в localStorage (переживает перезапуск),
кнопки Copy log и Clear log.

## День полон

Если в выбранном дне уже столько задач, сколько позволяет Settings →
Tasks per day, открывается шторка: день и красная метка «Full 3/3», ниже —
Make room for и новая задача, под ними задачи дня со знаком замены ⇄.
Тап по задаче — она уступает место и остаётся без даты (тост об этом
говорит); Cancel — ничего не меняется. Красный здесь по смыслу: день
требует решения сейчас.

## Даты и повтор

У задачи есть день (когда делать) и дедлайн (к какому сроку). День, время
и повтор ставятся в шторке даты: Today, Tomorrow, Next week, No date или
любая дата. Сделанная повторяющаяся задача ставит следующую — по правилу
повтора, не раньше завтра.

Задачи дня идут по времени, от ранней к поздней; без времени — ниже.
Порядок можно поменять руками: потянуть за номер или долгим нажатием на
строку. Ручной порядок главнее времени — его никто не пересчитывает;
по времени встаёт только новая задача или та, у которой время поменяли
(перед первой, что позже).

## Цели

Цель по числу (30 000 €, 5 км) или по шагам-чек-листу. Новая цель
набирается в поле внизу экрана: при вводе над ним открываются крутилки —
цель, сколько уже есть, шаг кнопок −/+, единица и срок; создаёт стрелка,
Enter не нужен. Крутилка — линейка с делениями по круглым числам: тянуть,
бросить (докатится), тапнуть по делению; точное число набирается в поле
слева. Шаг −/+ у готовой цели меняется кнопкой Step на карточке (или в
шторке «…»); Auto — шаг по величине цели. Шаги цели добавляются стрелкой
в поле Add a step.

## Удаление

Строку задачи смахивают влево — под ней кнопка Delete: на Today, в Plan и
в сферах. Ещё — Delete в раскрытой карточке задачи (два тапа) или
Select → Delete. Удаление насовсем, вместе с вложениями.

Сферу — в её шторке «⋯» → Delete sphere, двумя тапами: первый говорит,
сколько открытых задач уйдёт в All. Задачи сферы не удаляются.
Archive — то же без удаления: сфера прячется, её можно вернуть.

## Overview

Вкладка Overview (раньше Brief) — что требует внимания: завтра,
просроченное, дедлайны недели, цели. Ask AI about my plans кладёт в буфер
инструкцию с открытыми задачами и целями (как Copy with my data в
Settings → AI): её вставляют в любой ИИ-чат и спрашивают; правки из ответа
вставляются обратно в Settings → AI → Paste AI answer.

## Напоминания через Календарь

Веб-приложение на iPhone без сервера не может само показать уведомление
в заданное время. Поэтому у задачи с днём есть Add to Calendar (в карточке
задачи и строкой Reminder в шторке даты): приложение собирает файл события
`.ics` с днём, временем, повтором и оповещением, iPhone открывает его и предлагает добавить
его в Календарь, и оповещение показывает уже Календарь.

- с временем — событие на 30 минут, оповещение в момент начала, за 10 минут,
  за час или за день;
- без времени — событие на весь день, оповещение утром в 9:00 или накануне;
- если Календарь не открылся: Share or save .ics → Save to Files, затем
  открыть файл в Файлах → Add to Calendar;
- событие не связано с задачей: перенос или удаление задачи его не меняют.

Файл собирается на устройстве и никуда не отправляется.

## Импорт

Settings → Import from file, Paste a list или Paste AI answer. Файл копии
заменяет данные. Всё остальное **добавляется** к тому, что есть:

- сферы и цели сопоставляются по названию, новые создаются;
- задача с тем же названием в той же сфере уже есть — пропускается;
- у сферы можно указать цвет: `"color": "olive"` (названия — как в
  Settings → Appearance; другое слово — как без цвета, возьмётся свободный);
- запись с `id` существующей задачи, цели или сферы **меняет** её — только
  указанные поля; с `"delete": true` — удаляет (задачу — с вложениями);
  незнакомый `id` у новой записи не мешает — она добавится;
- перед записью показывается сводка (что добавится, изменится, удалится —
  удаляемое по названию), ничего не меняется без подтверждения.

## Через ИИ

Settings → AI. Любой ИИ-чат (ChatGPT, Claude, Gemini…) заполняет или
правит трекер:

1. **Copy instructions** — в буфере инструкция: формат, правила, пример,
   сегодняшняя дата и лимит дня. Вставить в чат и дописать просьбу
   («разложи мой переезд на задачи на две недели»).
2. **Copy with my data** — то же плюс открытые задачи, сферы и цели с `id`:
   так ИИ может отметить сделанным, перенести, удалить, обновить прогресс цели.
   Данные уходят только в тот чат, куда их вставили.
3. Ответ чата скопировать целиком → **Paste AI answer**: JSON находится
   в блоке кода или посреди текста, дальше — сводка и подтверждение.

Инструкцию собирает `aiPrompt` в `src/io.js`; пример из неё тест прогоняет
через импорт, так что он всегда рабочий. Правки в формате ответа:

```json
{ "tasks": [ { "id": "…", "status": "done" }, { "id": "…", "day": "2026-10-02", "time": "18:00" },
             { "id": "…", "delete": true } ],
  "goals": [ { "id": "…", "current": 5200, "step": 250,
               "steps": [{ "title": "Sell the bike", "done": true }] } ],
  "spheres": [ { "id": "…", "name": "Home", "archived": true } ] }
```

Поля принимаются под разными именами, всё, кроме названия, необязательно:

**Текст или Markdown** (`.txt`, `.md` или вставка): задача — строка или пункт
списка, заголовок `# Работа` или строка `Работа:` — сфера для задач ниже,
пункт с отступом — подзадача, `- [x]` — сделано. Метки в строке: `@today`,
`@tomorrow`, `@2026-10-01` — день; `due:2026-10-05` — дедлайн; `!`, `!high`,
`!low` — приоритет.

```
# Work
- Send the report @today !
  - attach numbers
- Call the bank due:5.10.2026
```

**CSV** (Excel, Numbers, Google Sheets, выгрузка Notion): разделитель — запятая,
точка с запятой или табуляция; столбцы узнаются по шапке: `title`/`name`,
`sphere`/`project`, `status`, `priority`, `deadline`/`due`, `day`, `note`,
`subtasks` (через `;`). Без узнаваемой шапки первый столбец — название.

**JSON**:

```json
{
  "spheres": [{ "name": "TTS", "glyph": "circle", "color": "olive" }],
  "tasks": [{
    "title": "Название",
    "sphere": "TTS",
    "status": "todo | doing | paused | done",
    "priority": "high | medium | low",
    "deadline": "2026-10-01",
    "day": "2026-09-25", "time": "09:30", "repeat": "daily | weekdays | weekly | monthly",
    "subtasks": ["шаг", { "title": "шаг", "done": true }],
    "note": "заметка"
  }],
  "goals": [{ "title": "Цель", "target": 10, "current": 2, "unit": "откликов", "step": 1,
              "deadline": "2026-12-31", "steps": ["шаг"] }]
}
```

Синонимы: `name`/`title`, `due`/`deadline`, `notes`/`note`, `checklist`/`subtasks`;
статус и приоритет понимаются и по-русски («в работе», «высокий»). Массив
в корне файла — это список задач. Глифы сфер: `circle pill square bar
triangle ring half diamond`; цвета: `olive lavender apricot mint slate lilac
plum khaki`.

## Шрифт

Geist (The Geist Project Authors / Vercel, SIL OFL 1.1) — гротеск
с кириллицей. Файлы и лицензия — в `tracker/fonts`, кредит — в Settings.
Межбуквенные — как в шрифте; заголовки, подписи, вкладки и кнопки — капсом.
Описания (пояснения под настройками, подсказки на пустых экранах) — тише:
14/20, обычный вес, чуть разреженно (0.005em), серым, без висячих коротких
строк; текст шторок и вводные абзацы — 15/22 тем же ритмом.
Switzer (Fontshare, ITF FFL) не подошёл: в нём нет кириллицы, а его
лицензия не разрешает держать файлы в открытом репозитории.

## Устройство

Обычный JavaScript (ES-модули) и CSS, без фреймворка и без пакетов; сборщика нет —
сборка копирует папку и вписывает в service worker версию (хэш содержимого)
и список файлов для офлайна.

| Файл | Что |
|---|---|
| `src/logic.js` | правила: лимит дня, просроченные, планирование, поиск, цели, Overview, цвета сфер |
| `src/io.js` | резервная копия (с вложениями) и импорт: JSON, CSV, текст; инструкция для ИИ |
| `src/look.js` | оформление до первого кадра (копия из localStorage) |
| `src/views/pickers.js` | поле новой задачи с чипами, меню, шторка даты |
| `src/views/files.js` | вложения задачи |
| `src/views/lab.js` | лаборатория вибрации (эксперимент, флаг) |
| `src/views/calendar.js` | напоминание: событие для Календаря (.ics) |
| `src/views/dial.js` | крутилка — линейка с делениями (цели) |
| `src/store.js`, `src/db.js` | состояние в памяти и IndexedDB |
| `src/views/*` | экраны |
| `sw.js` | офлайн-кэш |

## Архив

`tracker/archive/` — то, что сделано и снято с приложения, но не выброшено.
В сборку и офлайн-кэш папка не попадает.

- **Заставка при запуске** (`preloader.js`, `preloader.css`): пять иконок
  разделов в ряд, по ним прыгает чёрная пилюля, под ними тонкая линия
  загрузки. Снята: держала экран не меньше секунды и мешала быстрому вводу.
  Вернуть: перенести оба файла в `tracker/src/` (стили — в конец `app.css`
  или отдельной ссылкой в `index.html`), в `src/main.js` вызвать
  `showPreloader()` в начале `boot()`, `progress()` по шагам загрузки
  и `done()` после `enter()`.

## Команды

```
npm run test:tracker    # правила без браузера (входит в npm run check)
npm run build:tracker   # dist/tracker; в npm run build идёт последним
npm run tracker:fonts   # один раз на смену шрифта: Geist → tracker/fonts
npm run tracker:icons   # один раз на смену иконки: PNG → tracker/icons
```

Из исходников трекер открывается dev-сервером Vite по адресу `/tracker/`;
service worker там не ставится (версия `dev`), офлайн проверяется на сборке.
