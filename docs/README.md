## Метод

1. **Общие документы.** Продуктовый (зачем и для кого) и архитектурный (как устроено
   сейчас). Без них PRD висит в воздухе.
2. **PRD.** Требования и критерии приёмки. Открытые вопросы выписаны отдельно:
   решение принимает Эльдар, а не код.
3. **Декомпозиция.** PRD → Epics → User Stories → Tasks → Subtasks.
   - Epic пишется гипотезой: «если сделаем X, то Y; поймём по Z».
   - Story — «как <кто>, я <что>, чтобы <зачем>», с критериями приёмки.
   - Task — единица работы на полдня или меньше. Subtask — шаг внутри неё.
4. **Архитектурный план поверх всего scope.** Его делаем, когда видны все epics,
   а не по одной фиче. Только так видно, что три фичи просят одно и то же основание.
5. **Техдолг заложен с первого дня:**
   - **Enabler epics** — работа, которая не видна посетителю, но нужна, чтобы
     видимые фичи ехали без переделок. Четыре типа по SAFe: exploration (разведка),
     architecture (основания), infrastructure (окружение, сборка, CI),
     compliance (проверки, доступность, правила). Приоритет у них по тем же
     правилам, что у фич; делаются по частям, чтобы вовремя поправить курс.
   - **Architectural Runway** — код, компоненты и инфраструктура, которые уже есть
     и позволяют сделать ближайшие фичи без переделки. Фичи runway расходуют,
     enablers его наращивают. Правило: enablers под следующий epic готовы
     до того, как epic начат.
   - **Ёмкость:** в каждом цикле около 30% времени уходит на enablers и долг,
     70% на видимые фичи. Цифра наша, а не из SAFe: там сказано только, что
     ёмкость под enablers надо выделять явно.
   - **Реестр долга** ведётся в [05-runway.md](05-runway.md): что, чем вредит
     сейчас, какой enabler закрывает.

## Статусы в backlog

`todo` · `ready` (есть критерии приёмки и снят блокер) · `doing` · `done` · `blocked` (с причиной)

## Definition of Done (для любой задачи)

- `npm run check` зелёный: токены сверены, страж молчит;
- есть путь для `prefers-reduced-motion`, клавиатурный фокус виден;
- на 402 px ширина страницы не растёт ни в одной точке прокрутки;
- в консоли нет ошибок, на MacBook держится 60 fps;
- эффект прошёл «тест одной фразы» (см. [01-product.md](01-product.md#принципы));
- документы, которые описывают изменённое место, обновлены в том же коммите.
