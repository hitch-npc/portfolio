# Архитектура: как устроено сейчас

Статус: снимок на 18 сентября 2026. Целевая архитектура описана в [05-runway.md](05-runway.md).

## Стек

- Vite 8, чистый JS (ES modules) и CSS. Фреймворка нет.
- Сборка в один файл `dist/index.html` (`vite-plugin-singlefile`): стили и скрипты
  встроены, страницу можно открыть без сервера.
- CSP кладётся мета-тегом при сборке (`vite.config.js`): скрипты пускаются по sha256,
  сетевых запросов у страницы нет.
- Деплой: GitHub Actions (`.github/workflows/pages.yml`) → GitHub Pages,
  перед сборкой гоняется `npm run check`.

## Пайплайн значений

```
tokens.json ──build-tokens──▶ src/styles/tokens.css (:root, руками не правится)
vendor/tts ───build-tts─────▶ ядро кейса TTS под .tts (цвета клиента)
Fontshare ────fetch-fontshare▶ public/fonts/fontshare/ (не в репозитории, лицензия)
                               │
tooling/guardrail.mjs ◀────────┘ страж: сырой #hex вне :root, радиус не из токенов,
                                 анимация без reduced-motion, outline без :focus-visible
```

## Страница

Одна страница, `index.html` (~50 КБ). Порядок сверху вниз:

1. Прелоадер: лента из линз, процент, сменяющиеся строки.
2. Topbar: «The Black Cat Studio™» и «Valencia · ES», переживает прокрутку.
3. Hero: знак TBCS на холсте, имя, роль, подсказка про прокрутку.
4. Skills: четыре пункта, зрачок (`iris`) повторяет активный.
5. Work: колода из двух карт. TTS с живым макетом, вторая карта «Coming soon».
6. Кейс TTS: `<dialog>`, раскрывается из карты, свёрстан на ядре TTS.
7. VHS-плёнка поверх всего экрана.

**Контакта, About и CV на странице нет.**

## Ограничения, которые держим

- **Доступность.** Для каждого движения есть путь `prefers-reduced-motion`,
  `:focus-visible` описан везде, где снят `outline`. Холсты `aria-hidden`,
  смысл дублируется текстом (`sr-only` у знака).
- **Производительность.** Поле: около 8000 стрелок одним `stroke` на корзину
  яркости, 128 `stroke` за кадр. Холсты за экраном не рисуются
  (`IntersectionObserver`). Чтения и записи геометрии разведены через `frame.js`.
- **Мобильный Safari.** Секции с трансформами режут горизонталь
  (`overflow-x: clip`), иначе Safari сжимает страницу целиком.
- **Безопасность.** Отладочные ручки (`window.__*`, `?tune`) только в dev и
  вырезаются из сборки. Шрифты свои, Google не участвует.
- **Цвета клиента.** `.tts` живёт на токенах TTS, портфолио на своих.

## Расхождения, найденные при разборе

- В `README.md` написано, что страж валит «border-radius больше 8px». На деле
  правило строже: радиус только из токенов `--r-*`.
- `PLAN.md` описывает hero как супрематическую композицию на WebGL. В коде знак
  рисуется на 2D-холсте полем стрелок. Там же 14 рядов в высоту прописной,
  в коде `rowsPerCap: 22`.
- Проверка «reduced-motion» есть в трёх копиях: `decrypt.js`, `work.js`, `case.js`.
- Рабочее дерево не закоммичено: 15 изменённых файлов, 4 новых
  (`frame.js`, `rays.js`, `sandbox/`, `gallery.html`).

Все расхождения заведены в реестр долга: [05-runway.md](05-runway.md#реестр-техдолга).
