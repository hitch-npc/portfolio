# Архитектурный план, runway и техдолг

Статус: 18 сентября 2026, R1 сделан. План построен поверх всего scope R1–R4
([04-backlog.md](04-backlog.md)), а не под одну фичу.

## Целевая структура

```
src/
  main.js              только загрузка и порядок
  motion/              всё про движение, одно место на весь сайт   ← EN-3 ✓
    reduced.js         одна проверка prefers-reduced-motion
    frame.js           общий кадр прокрутки
    visibility.js      пауза холстов за экраном
    decrypt.js         дешифровка + привязка по [data-decrypt]
  field/               движок поля: правило отдельно, фигура отдельно ← EN-2 ✓
    glyph-field.js     покрытие, поток, вихрь, инверсия, корзины
    shapes.js          arrow, triangle; dot — для обложек кейсов (EP-7)
  brand/preloader.js
  sections/            skills, iris, work, case
  styles/              light.css — свет на акцентах
content/cases/         разметка кейсов, вставляется при сборке ← EN-4
tooling/               токены, TTS, шрифты, страж, проверки вёрстки ← EN-5
field.html, gallery.html  песочницы, только dev-сервер
docs/
```

Уже удалены: `brand/vhs.js`, `brand/rays.js`, `styles/overlay.css`.
Уже на месте после R1: `motion/`, `field/` (кроме `dot`), `light.css`.
Ещё нет: `content/cases/` (EN-4), проверки вёрстки в `tooling/` (EN-5), фигура `dot` (EP-7).

## Runway: что нужно каждому epic

Runway — то, что уже есть в коде и позволяет сделать фичу без переделки.
Фичи его расходуют, enablers наращивают.

| Epic | На что опирается | Есть сейчас? | Кто достраивает |
|---|---|---|---|
| EP-1 · треугольники | фигура отдельно от поля | да, с R1 | EN-2.1 ✓ |
| EP-1 · строка с идеей | число фигур из поля, дешифровка | да, с R1 | EN-2.2 ✓, EN-3.2 ✓ |
| EP-1 · метки секций | дешифровка по атрибуту | да, с R1 | EN-3.2 ✓ |
| EP-1 · свет, теги | токены, генератор, страж | да | — |
| EP-2, EP-3 · контакт, About | токены, базовые стили | да | — |
| EP-4 · кейс TTS | сборка ядра TTS | да | — |
| EP-5 · второй кейс | кейсы вне `index.html` | нет | EN-4 |
| EP-6 · запуск | CI и Pages | да | — |
| EP-6 · уверенность в вёрстке | автопроверки ширины, консоли, reduced-motion | нет, проверяем глазами | EN-5 |
| EP-7 · обложки растром | фигура `dot` на движке | после EN-2 да | — |

**Горизонт runway — один релиз вперёд.** Enablers текущего релиза делаются первыми.
Enablers следующего релиза идут в 30% ёмкости текущего: EN-4 во время R2.
EN-5 в R1 не влез, поэтому в R2 он первый — до запуска. Так R2 и R3 стартуют
на готовом основании.

## Решения

Короткие записи в духе ADR: что решили, почему, при каком условии пересматриваем.

| # | Решение | Почему | Пересмотреть, если |
|---|---|---|---|
| D-01 | `tokens.json` — единственный источник значений, `tokens.css` генерируется | Метод из кейса TTS, сайт его доказывает | никогда: на этом стоит позиционирование |
| D-02 | Hero на Canvas 2D, не WebGL | Около 12 800 фигур рисуются за 2,4 мс на кадр, three.js убран | понадобится 3D или фигур станет больше 30 000 |
| D-03 | Каждый эффект проходит тест одной фразы, реестр в [01-product.md](01-product.md#реестр-эффектов) | Отзыв 18.09: эффектов много, смысл теряется | — |
| D-04 | Неон заменён тёплым светом: вольфрам и нить накала. Фиолетовый остался только в короне зрачка (`--iris-*`) | Меньше неоновой темы. Глаз по решению Эльдара не трогаем, поэтому у него своя палитра | вернёмся к зрачку после теста пяти секунд |
| D-05 | Знак из треугольников, фигура поля сменная | Треугольник — простейшая залитая фигура, читается как единица системы. Сменная фигура нужна и для обложек | тест пяти секунд не проходит |
| D-05a | В строке «N triangles» считаются все фигуры поля, включая фон | Фон подчиняется тому же правилу, иначе порог «что считать буквой» был бы произвольным | — |
| D-05b | Корзины поля режутся на пачки по 32 фигуры | Заливка пути из 10 000 контуров — 90 мс на кадр, пачками — 2,4 мс | — |
| D-05c | Под курсором лупа, а не расталкивание; знак дышит волной размера | Расталкивание пробивало дыру (отзыв 18.09), лупа растягивает середину без просветов. «Больше дыхания» — там же | — |
| D-05d | Корзин яркости 64, а не 128 | Кадр 2,96 мс против 3,55 мс, ступень прозрачности 0.015 на глаз не видна | появятся полосы на плавных переходах |
| D-06 | VHS и лучи за тегами убраны | Не проходят тест одной фразы | — |
| D-07 | Движение живёт в одном модуле `motion/` | Три копии проверки reduced-motion, дешифровка вшита в одну секцию | — |
| D-08 | Кейсы в отдельных файлах (R3) | Второй кейс не должен удваивать `index.html` | — |
| D-09 | Сборка в один файл, CSP по хэшам скриптов | Страница открывается где угодно, внедрённый скрипт не выполнится | понадобится внешний ресурс |
| D-10 | Прелоадер и зрачок в R1 не трогаем | Решение Эльдара от 18.09 | после теста пяти секунд |
| D-11 | Сначала лид на фриланс, потом найм. Фото и CV не публикуем | Решение Эльдара от 18.09 | после Q10 |
| D-12 | Теги — один нейтральный тон, статичная тусклая обводка | Тег — метка, а не действие. Цвет категорий спорил с монохромом сайта | — |

## Реестр техдолга

«Проценты» — чем долг мешает прямо сейчас.

| # | Долг | Проценты | Закрывает | Статус |
|---|---|---|---|---|
| TD-1 | Рабочее дерево не закоммичено: 15 изменённых файлов, 4 новых | Правки R1 смешаются с работой прошлой недели, откатить по одной нельзя | EN-1.1 | closed, тег `v0.2-before-clarity` |
| TD-2 | Проверка reduced-motion в нескольких копиях | Новый эффект легко забудет её или проверит иначе | EN-3.1 | closed, R1 |
| TD-3 | Дешифровка вшита в `work.js` | Каждое новое место — новый код | EN-3.2 | closed, R1 |
| TD-4 | Стрелка вшита в движок поля | Треугольники и точки превратятся в два форка движка | EN-2.1 | closed, R1 |
| TD-5 | `index.html` 50 КБ, кейс внутри | Второй кейс удвоит файл, правки будут задевать друг друга | EN-4.1 | open |
| TD-6 | Инлайновые `style="…"` в кейсе | Отступы в разметке, а не в стилях: страж видит hex, но не систему отступов | EN-4.2 | open |
| TD-7 | Документы расходятся с кодом (README про радиус, PLAN про WebGL и 14 рядов) | Следующий агент или человек будет работать по неверному описанию | EN-6.1 | closed, R1 |
| TD-8 | Ширина на 402 px, reduced-motion и время кадра проверяются вручную | Регресс, как было с Safari, найдётся после деплоя. В R1 заливка треугольников съела 90 мс на кадр, и это нашёл только ручной замер | EN-5 | open |
| TD-9 | Песочница импортирует `vhs.js` | После удаления плёнки песочница сломается | Task 1.3.1 | closed, R1 |
| TD-10 | Нет продуктовых метрик TTS | Кейс сильный по ремеслу, но молчит о бизнесе | FR-K2 (заглушка), цифры от Эльдара | open |
| TD-11 | Примитивы `--tag-*`, `--mauve`, `--lilac`, пастель остались без потребителей на сайте (только песочница и корона зрачка) | Лишние значения в токенах, их легко взять по ошибке | чистка токенов после решения по зрачку | open |

Правило: новый долг, найденный в работе, сначала попадает сюда, потом в backlog.
Закрытый долг остаётся в таблице со статусом `closed` и ссылкой на коммит.
