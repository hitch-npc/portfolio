## Требования

### Hero (EP-1)

| ID | Требование | Приёмка |
|---|---|---|
| FR-H1 | Знак TBCS рисуется полем **треугольников** вместо стрелок. Треугольник равнобедренный, залитый, вершиной по направлению поля. Размер и яркость от покрытия | Знак читается на 402, 1280 и 2560 px. Ниже 620 px стоит в две строки TB / CS |
| FR-H2 | Вихрь от курсора сохраняется. Курсор ушёл, и знак возвращается в форму | Курсор проводится через знак и убирается: через секунду рисунок тот же |
| FR-H3 | Под знаком одна строка с идеей, английский, до 60 знаков. Дешифруется один раз после ухода прелоадера | Текст по [Q1](#открытые-вопросы). Если в строке число, оно берётся из поля (видимые треугольники при текущем размере), а не вписано руками |
| FR-H4 | Скринридер получает строку сразу, без мусорных символов | VoiceOver читает итоговую строку |
| FR-H5 | Подсказка «Scroll down when you're done playing» заменяется строкой с идеей, стрелки прокрутки остаются | [Q8](#открытые-вопросы) |
| FR-H6 | Reduced motion: один статичный кадр треугольников, строка появляется сразу | Проверка с включённой настройкой ОС |

## Нефункциональные требования

- 60 fps на MacBook при прокрутке и движении курсора, в консоли нет ошибок.
- На 402 px ширина страницы не растёт ни в одной точке прокрутки.
- Reduced motion даёт то же содержание без движения.
- Клавиатура доходит до всего интерактивного, фокус виден.
- Контраст текста не ниже 4,5:1.
- Запросы только к своему домену (CSP).
- Вес сборки меряем в EN-1. Рост больше чем на 10% за релиз требует объяснения в CHANGELOG.

## Открытые вопросы

| # | Вопрос | Варианты | Рекомендация |
|---|---|---|---|
| Q1 | Текст строки с идеей | A. «8 214 triangles. One rule.» (число для примера: живое, из поля, зависит от экрана) · B. «Every triangle follows one rule. That's a design system.» · C. «One rule instead of a hundred decisions.» | **A.** Коротко, число настоящее, это жест design engineer. Перекликается с кейсом «nothing gets decided twice» |
| Q2 | Дыхание инверсии в поле | убрать / оставить | **Убрать.** Фраза «знак читается в негативе» к идее не относится, и это третий приём в hero |
| Q3 | Оттенки тегов | пастельные по категориям, тусклее / один нейтральный | **Оттенки оставить, тусклее.** Цвет несёт смысл: категорию |
| Q4 | Цвет луча | нейтральный белый от `--paper` / тёплый белый | **Нейтральный.** Палитра сайта чёрно-белая, тёплый оттенок был бы новым цветом |
| Q5 | Что считать подзаголовками | метки секций («Skills», «Cases») · заголовки h2 · названия карт | **Метки и названия карт.** h2 набраны Gambarino, перебор символов в антикве выглядит сломанным шрифтом. Проверить на прототипе |
| Q6 | Карта «Coming soon» на запуске | скрыть / оставить / заменить кейсом о сайте | **Скрыть**, пока нет второго кейса. Пустая карта говорит «не доделано» |
| Q7 | Контакты | почта, LinkedIn, текст CV | От Эльдара |
| Q8 | Подсказка про прокрутку | заменить строкой с идеей / оставить обе | **Заменить.** Одна строка, как договорились |
| Q9 | Фото для About | есть / снять | От Эльдара |
